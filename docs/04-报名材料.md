### Project idea summary

**长版（约 200 词，适合多行文本框）**

```
FOREIGN is a first-person horror anomaly hunt set inside a 3D-reconstructed real room.

A real apartment is captured once with Aholo 3DGS reconstruction. You walk it in
first person. It looks like an ordinary home, and that is the problem: every floor,
something in it does not belong. A pale face hangs in the air at head height,
turned to watch the door. A porcelain doll sits where the kettle was. The same
floor lamp has become five floor lamps. Find everything that is wrong before the
timer runs out, then descend to the next floor — the same room, re-shuffled.

The rule is deliberately judgeable at a glance: mark anything that could not exist
in a normal home. No memorising, no comparing against a previous run. You get three
marks for the whole floor, so guessing is a losing strategy.

The design bet is that reconstruction should be playable, not just browsable. The
room is authored once, so art cost is fixed; all variation comes from AI-generated
3D content. Anomalies are produced with Aholo Lux3D text-to-3D from a catalogue of
prompts, normalised to real-world scale, and dropped into the scene at runtime.
Nothing about the game works without generated 3D content — the tool is the content
engine, not a garnish.

Every object also has a procedural placeholder, so the build is always playable and
Lux3D assets swap in without touching game logic.
```

**短版（约 55 词，适合单行或限长字段）**

text-to-3D: generated content is the game's content engine, not a garnish.

```
FOREIGN 是一个发生在 3D 重建真实房间里的第一人称恐怖找异常游戏。

用 Aholo 3DGS 把一间真实公寓重建一次，玩家以第一人称在其中行走。它看起来就是
一间普通的家——问题就出在这里：每一层都有东西不属于这里。一张惨白的脸悬在
人的高度，转过来盯着门口；一只瓷娃娃坐在本该放水壶的位置；同一盏落地灯变成了
五盏。在时间耗尽前找出全部不对劲的东西，然后下潜到下一层。

规则刻意做得「一眼可判」：标记任何不可能出现在一个家里的东西。不需要背房间，
不需要跟上一层对比。每层只有 3 次标记机会，所以乱点必输。

我们的核心判断是：空间重建应该「可玩」，而不只是「可浏览」。房间只制作一次，
美术成本固定；所有变化都来自 AI 生成的 3D 内容。异常由 Aholo Lux3D 文生 3D
根据一份 prompt 清单生成，归一到真实尺寸后运行时放入场景。没有 AI 生成的 3D
内容，这个游戏完全不成立——工具是内容引擎，不是点缀。

每个物件同时都有程序化占位模型，因此构建永远可玩，Lux3D 资产可以随时替换进来
而不改动任何玩法逻辑。
```

### API key 步骤

1. 打开 **https://labs.aholo.ai/** —— 这是 Aholo Spatial Labs 控制台。
   国内网络用 **https://labs.aholo3d.cn/**（同一个账号体系，网关在国内）。
2. 注册 / 登录（邮箱或第三方登录）。
3. 进 **API Keys** 页面：https://labs.aholo.ai/api-keys
4. 点创建（按钮大概是 `Create API Key` / `New Key`），**立刻复制**——
   多数平台只显示一次。
5. **把 key 填进 `.env.local`（这一步只能你来做）**

   我的文件工具被安全策略禁止创建 `.env.local` 这类密钥文件（`secret.pattern.env-variant`），
   这是设计如此，我不会绕过。请你手动建：

   在 `D:\26-fallwin\生活\游戏\aholo-hackathon\` 下新建文件 `.env.local`，内容一行：

   ```
   AHOLO_API_KEY=你复制的那串
   ```

   没有编辑器的话，在 PowerShell 里跑（把 `你的KEY` 换掉）：

   ```powershell
   Set-Content -Path 'D:\26-fallwin\生活\游戏\aholo-hackathon\.env.local' -Value 'AHOLO_API_KEY=你的KEY' -Encoding utf8
   ```

   `.env.local` 已经在 `.gitignore` 里，不会被提交。

6. **告诉我你填好了**，我会先跑一个**只读**的验证命令确认 key 有效（不消耗额度）：

   ```
   npm run key:check
   ```

   看到 `✓ authenticated` 就说明没问题，然后我再跑 `npm run assets:generate`
   把 15+ 个异物一次性生成完。

> 🔐 **关于刚才贴给我的那个 key**：我只把它记在对话里，**没有**写进任何文件。
> 如果这个 key 之后可能出现在公开的地方（截图、直播、仓库），
> 去 labs 后台**删掉重建一个**最省心。

> ⚠️ **我看不到 labs 的界面**（也是 JS 渲染的）。如果你点进去发现位置不一样，
> 把界面截图发我，或者告诉我你看到哪些菜单，我带你走。

> 💡 **免费额度可能不够**：规则里 `Export in all supported formats` 和
> `Commercial use of generated models` 都列在 PRO 权益下（$14.9/月）。
> 如果你能生成但在导出 GLB 或商用授权上被卡，就是这一条——
> 到时候再决定要不要开一个月。**不建议现在就付费**，先跑通再说。

### 备用方案（不开 API 也能推进）

如果拿 key 有阻力，用 **Lux3D 网页版**手动生成：

1. https://lux3d.aholo.ai/lux3d/home
2. 逐个粘贴 `npm run assets:plan` 打印出来的 prompt（15 条）
3. 导出 GLB
4. 按 key 命名放进 `public/assets/foreign/<key>.glb`：
   `duck.glb` `cone.glb` `gnome.glb` `milk.glb` `cactus.glb` `vending.glb`
   `washer.glb` `toilet.glb` `flamingo.glb` `astronaut.glb` `shark.glb`
   `horse.glb` `mannequin.glb` `piano.glb` `eye.glb`
5. 刷新页面即可，游戏自动加载——**顺序无所谓，先做 3 个也能跑**
