### Project idea summary

**长版（约 200 词，适合多行文本框）**

```
FOREIGN is a first-person anomaly hunt set inside a 3D-reconstructed real room.

A real apartment is captured once with Aholo 3DGS reconstruction. You walk it in
first person. Every floor is that same room, re-shuffled — and something in it is
wrong. An object has been replaced by something that has no business being there:
a metre-tall rubber duck on the living-room rug, a great white shark hovering over
the bed, a vending machine where the bookshelf stood. Find every anomaly before the
timer runs out, then descend to the next floor.

The design bet is that reconstruction should be playable, not just browsable. The
room is authored once, so art cost is fixed; all variation comes from AI-generated
3D content. Anomalies are produced with Aholo Lux3D text-to-3D from a catalogue of
prompts, normalised to real-world scale, and dropped into the scene at runtime.
Five anomaly types (intrude, vanish, shift, warp, twin) and two difficulty axes
(count and subtlety) keep the loop fresh. Nothing about the game works without
generated 3D content — the tool is the content engine, not a garnish.

Every object also has a procedural placeholder, so the build is always playable and
Lux3D assets swap in without touching game logic.
```

**短版（约 55 词，适合单行或限长字段）**

FOREIGN 是一个发生在 3D 重建真实房间里的第一人称找异常游戏。

用 Aholo 3DGS 把一间真实公寓重建一次，玩家以第一人称在其中行走。每一层都是

## 2 · 怎么拿 Aholo API key

三件互相独立的事，别混：

| 要做什么 | 去哪 | 是否必需 |
| --- | --- | --- |
| **报名比赛** | https://www.aholo.ai/hackathon/register | 必需 |
| **注册 Lux3D** | https://lux3d.aholo.ai/lux3d/home | **必需**（规则强制要求用 Lux3D） |
| **拿 API key** | https://labs.aholo.ai/api-keys | 可选，但走了就能一键生成全部异物 |

### API key 步骤

1. 打开 **https://labs.aholo.ai/** —— 这是 Aholo Spatial Labs 控制台。
   国内网络用 **https://labs.aholo3d.cn/**（同一个账号体系，网关在国内）。
2. 注册 / 登录（邮箱或第三方登录）。
3. 进 **API Keys** 页面：https://labs.aholo.ai/api-keys
4. 点创建（按钮大概是 `Create API Key` / `New Key`），**立刻复制**——
   多数平台只显示一次。
5. 把 key 给我，或者你自己填进项目里的 `.env.local`：

   ```
   AHOLO_API_KEY=你复制的那串
   ```

   文件在 `D:\26-fallwin\生活\游戏\aholo-hackathon\.env.local`
   （可以先复制 `.env.example`）。

6. 然后我跑 `npm run assets:generate`，15 个异物一次性生成完。

> ⚠️ **我看不到 labs 的界面**（也是 JS 渲染的）。如果你点进去发现位置不一样，
> 把界面截图发我，或者告诉我你看到哪些菜单，我带你走。

> 💡 **免费额度可能不够**：规则里 `Export in all supported formats` 和
> `Commercial use of generated models` 都列在 PRO 权益下（$14.9/月）。
> 如果你能生成但在导出 GLB 或商用授权上被卡，就是这一条——
> 到时候再决定要不要开一个月。**不建议现在就付费**，先跑通再说。

### 备用方案（不开 API 也能推进）

如果拿 key 有阻力，用 **Lux3D 网页版**手动生成：

1. https://lux3d.aholo.ai/lux3d/home
2. 逐个粘贴 `npm run assets:plan` 打印出来的 prompt（15 条）
3. 导出 GLB
4. 按 key 命名放进 `public/assets/foreign/<key>.glb`：
   `duck.glb` `cone.glb` `gnome.glb` `milk.glb` `cactus.glb` `vending.glb`
   `washer.glb` `toilet.glb` `flamingo.glb` `astronaut.glb` `shark.glb`
   `horse.glb` `mannequin.glb` `piano.glb` `eye.glb`
5. 刷新页面即可，游戏自动加载——**顺序无所谓，先做 3 个也能跑**
