# FOREIGN · 异物

> 一间被 3D 重建的真实房间。每一层都有东西被改过。
> 在时间耗尽之前，把**不属于这里的东西**全部找出来。

参赛作品，**Manycore Aholo Global 3D AI Hackathon**（2026.10.19 – 11.19）。

---

## 一句话

把"空间重建"从**可浏览**变成**可玩**：场景只做一次，内容由 **Aholo Lux3D** 生成的 3D 物件无限供给。

## 为什么这样设计

评审权重 **30% 用 Manycore 工具 + 25% 好玩 = 55%**。所以最优解不是炫技 demo，而是
**玩法必须依赖 AI 生成的 3D 物件**——没有 Lux3D 就没有游戏内容。

| 设计决策 | 原因 |
| --- | --- |
| **一间房，无限层** | 美术成本 = 一间房。变化的是物件状态，不是场景。完成度天然高。 |
| **异常由 AI 物件供给** | Lux3D 是内容引擎，不是贴图库 → 工具分是"核心"而非"装饰"。 |
| **没资产也能玩** | 每个道具都有程序化占位模型；GLB 到位后按 key 自动替换。**缺资产永远不是崩溃。** |
| 成熟的爽点机制 | 「看—怀疑—确认」是经过验证的（8 番出口式），2 分钟上手，短视频好看。 |

## 玩法

同一个房间（10 × 8.6 m，客厅 / 厨房 / 卧室 / 玄关），每层重新排布。
每层有 N 个异常，五种类型：

| 类型 | 内容 |
| --- | --- |
| `intrude` | **凭空多了一件 AI 生成的东西**（Lux3D 资产） |
| `vanish` | 本来在的东西不见了 |
| `shift` | 东西被挪了位置或浮在半空 |
| `warp` | 尺寸或颜色被改了 |
| `twin` | 东西被复制了一份 |

准星对准，左键标记。标对得分（剩余时间越多分越高），标错扣 8 秒。找齐下潜一层，时间归零结束。

难度两条轴：**数量**（1→6）和**隐蔽度**（前几层只用显眼的异常）。
第 1 层固定刷一只巨型橡皮鸭在客厅正中央——用来教会玩家"这个房间"和"这个动词"。

## 技术栈

```
Vite 8 · TypeScript 7 · three.js 0.186 · Vitest · Playwright
```

```
src/
  game/
    types.ts      纯类型，不含 three.js
    catalog.ts    房间的唯一真相：墙体、34 个家具槽位、10 个生成点、15 个 AI 异物定义
    layout.ts     纯几何：旋转后包围盒、重叠、是否穿墙 —— 关卡正确性可测试
    rules.ts      纯规则：种子随机、楼层生成、判定、计分 —— 不需要浏览器
    props.ts      每个道具都用图元搭出来（占位模型 + 兜底）
    Room.ts       静态外壳建一次；每层重建道具，避免异常跨层泄漏
    Player.ts     第一人称，带阻尼的移动 + AABB 碰撞
    assets.ts     载入 Lux3D 的 .glb，归一化尺寸与轴心
    Game.ts       循环、状态机、全部界面
  aholo/
    client.ts     Aholo API 客户端（生成异物资产）
tools/
  shoot.mjs       无头验证 + 截图
```


## 验证

```bash
npm run verify     # typecheck + 单测 + 构建 + 无头实机验证
```

`tools/shoot.mjs` 不只是截图，它是**验收**。它会：

1. 在 Chromium（SwiftShader）里真的把游戏跑起来；
2. 逐帧统计亮度／颜色多样性，**画面全黑直接判失败**；
3. 在页面内发射线束，确认每个视角确实渲染出了家具；
4. 遍历 13 个站位 × 4 个朝向，做**精确遮挡测试**，确认
   **每一件家具都能在玩家站得到的地方看到**（防止道具被做到没人看得见的角落）；
5. 真的走一遍玩法：误标要扣时间且不加分，标对要计分并进入下一层；
6. 任何 page error / console error 都判失败。

单测覆盖种子随机可复现、难度曲线、异常生成不重复不越界、
**关卡几何无穿墙／无重叠／生成点可用**、判定与计分。

## 关卡正确性是被测出来的，不是看出来的

`tests/layout.test.ts` 会检查：家具不穿外墙、不埋进隔墙、
不互相重叠、锚点道具确实贴在墙上、每个生成点放得下东西。

它真的抓到过 bug：书柜和电视柜的旋转方向反了（1.5 m 插进墙里）、
衣柜和书桌越界、餐边柜和冰箱重叠、床和椅子重叠、
**玄关只有 1 米深根本放不下任何东西**（已加深到 1.6 m）。

## Aholo 集成

- **Aholo Lux3D（必需）**：生成 `FOREIGN_ASSETS` 里的异物。每个条目的英文 prompt
  写在 `catalog.ts`，导出的 `.glb` 放进 `public/assets/foreign/<key>.glb` 即自动生效。
- **Aholo API（可选）**：`src/aholo/client.ts` 用于在运行时按主题批量生成异物。
- **Aholo Viewer / 3DGS（方向）**：把程序化房间换成真实重建的 3DGS 空间。

生成结果没有统一的比例和轴心，所以 `assets.ts` 会按每个资产的目标高度做归一化，
并把底面重新对齐到 y = 0——否则"一盒牛奶"会以两米高进来。
